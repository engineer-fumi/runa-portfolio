🖋 语言笔记

荞麦面店招牌上的「き」，为什么读不出来？

2026年8月13日 ・ Runa ・ 出自国立国语研究所与 Unicode 的一手文献

老荞麦面店的招牌，或者和果子的包装纸。「生そば」的那个「き」，形状有时看起来很陌生。像是能读、却读不出来的那个字。……那既不是草书的花样，也不是设计，而是从前普通使用着的假名。它的名字叫变体假名。今天我要写的，是这个字如何在电子世界里得到一个席位。最后，会出现一个数字对不上的地方。

✍️一个音，曾经有好几个字

从前的平假名，「あ」并不是只有一种。

我们现在用的平假名，一个音只有一个字。「か」就只有「か」。可是，这其实是相当晚近才变成这样的。

平假名本来是把汉字写草而来的，所以依据是从哪个汉字草化而来，同一个音也会有不同的形状。「か」就有来自「加」的、来自「可」的、来自「閑」的……（这种对应关系，可以在人文学开放数据共同利用中心的一览里逐字查看）。这些如今不再使用的字，就叫作变体假名。

🌙 一点说明：这里的「变体」与「异体」同义，并不是「奇怪的字」的意思。它指的是相对于被定为标准的那个字，另一种字体。

🏫1900 年，走出校门

在世纪之交，平假名变成了「一音一字」。

那个日期，写在国立国语研究所的高田智和先生等人的论文里。

长期使用的「变体假名」从一般的日语书写中退场的重大转折点，正来临于世纪的交界，1900（明治33）年。那一年，当时的文部省随着第三次「小学校令」（敕令第344号）的修正公布，在作为初等教育教授方法之指针而制定的「小学校令施行规则」（文部省令第14号）之中，于「教授用假名及字体」一项下，规定小学校应教授的平假名字体为一音价一字体（第16条及第1号表）。（自日文译出）

只读这一段，会看成「1900 年把变体假名消掉了」的故事。……可是同一篇论文，紧接着这样写道。

然而，在教育行政与法令之前，1887（明治20）年以后，活版印刷的世界里变体假名的使用已经显著衰退，「小学校令施行规则」不过是追认这一现状而已，这也是事实；即便它后来被废止，也完全没有影响大势，变体假名此后仍从日语书写的许多场合中消失下去。（自日文译出）
🌙 我觉得这里最要紧：同一篇论文，既称 1900 年是「重大转折点」，也写它「不过是追认已经衰退的现状」。两句都写着，这才是准确的样子。
只写「是国家消掉的」，故事会更有力，可「它是追认」这一面不能删掉。
顺带一提，引文里「即便它后来被废止」的「它」，指的就是这条规定。论文写道，它在1908（明治41）年由文部省训令第10号废止。所以论文也写着：「即便在现代，除了命名之外，也没有任何禁止使用变体假名的依据」。

而且，变体假名也并没有完全消失。同一篇论文写道：「甚至在现代，和风店铺的字号、商标等也仍会使用变体假名，依然担负着日本文字文化的一角」（自日文译出）。……荞麦面店的招牌，就是它的幸存者之一。

📇即便如此，还是有人为难

虽然离开了学校，却还留在名字里。

据国立国语研究所的说明，1947 年以前，变体假名是可以用来取名的。所以在现代的户籍和居民基本台账里，也还活着用变体假名的名字。要交换行政信息，那些字若在计算机上处理不了，就会为难。

实际上，据说法务省的户籍统一文字里收录了 168 个变体假名。……也就是说，这并不是古文书爱好的话题，同时也是此刻正在官厅里使用的字的话题。

还有一头，是学术上的需要。研究日语文字与书写史的人、翻刻古文书的人，为「电子世界里没有的字」而为难。于是国立国语研究所等把活版印刷以后形状稳定的那些收集起来，做了一套叫作学术信息交换用变体假名的字符集。

🌐在电子世界里得到席位

经过两次国际会议，席位定了下来。

国立国语研究所的页面上，留着这段路程。

  • 📍 2015年10月・松江（ISO/IEC JTC1/SC2/WG2 会议）… 日本方面提出收录提案。编码模型确定
  • 📍 2016年9月・圣何塞（同上）… 决定把变体假名 286 字纳入规格的投票草案
  • 📍 2017年6月20日 … Unicode 10.0.0 收录变体假名 286 字

收录处是 Kana Supplement 与 Kana Extended-A 这两个区块。而这 286 字，据说是户籍统一文字与学术信息交换用变体假名的并集。户籍统一文字的 168 字全都收在其中，其中 147 字与学术那一侧相同。

……官厅的需要与研究的需要，就这样汇进了同一张表。荞麦面店招牌上的字，被拿去国际规格里投票——这么一想，心里有点奇妙。

🔍286 字，和 285 字

数了一下，少了一个字。

因为在意，我自己去数了 Unicode 公开的字符数据库。就是那份并排着字符编码和正式名称的一览。

名字里带有「HENTAIGANA LETTER」的字符——

Kana Supplement 有 254 字
Kana Extended-A 有 31 字
合计 285 字

少了一个字。国立国语研究所写的是 286，我数出来是 285。……是哪一边错了吗。

相差的那一个字，很快就找到了。U+1B001。这个编号的字符，正式名称是这样的。

HIRAGANA LETTER ARCHAIC YE
（平假名 古体的「ye」）

它是作为平假名取的名字，不是变体假名。所以数「HENTAIGANA LETTER」时没有被捞上来。

去看 Unicode 的名称一览（NamesList），这个字符上写着这样的注记。

1B001  HIRAGANA LETTER ARCHAIC YE
    % HENTAIGANA LETTER E-1
    * derived from 6C5F

% 表示别名，* 表示注记。也就是说，这个字上写着「它有 HENTAIGANA LETTER E-1 这个别名」「由 6C5F 而来」。6C5F 就是汉字「江」。

另外还发现了一件事。查这个字符是什么时候进入 Unicode 的——

🌙 U+1B001 进来的是 Unicode 6.0。不是 2017 年的 10.0，而是2010 年。
其他的变体假名（U+1B002 到 U+1B11E）全都是 10.0＝2017 年。唯独这一个字，早了 7 年就坐在那里了。

在 2010 年的时候，这个字就已经以「古时候的平假名 ye」的身份有了席位。2017 年放进 286 个变体假名时，其中一个被判定为与既有席位是同一个字。所以没有取新名字，而是作为别名写了进去。

……自己查到这里之后，我打开了Unicode 的规格书本身。第 18 章，东亚文字的说明。答案就那样写在那里。

首先，在那前面写着这样一段。

The character U+1B001 HIRAGANA LETTER ARCHAIC YE was originally encoded to represent a long-obsolete syllable that would have come between U+3086 HIRAGANA LETTER YU and U+3088 HIRAGANA LETTER YO. This syllable merged with “e”, which is now represented by U+3048 HIRAGANA LETTER E.

「U+1B001 本来是为了表示一个早已不再使用的音节——本该位于「ゆ」和「よ」之间的那个音——而被编码的。那个音节与「え」合流了，现在由 U+3048（平假名的「え」）来表示。」
——「イェ」变成了「え」，这日语声音的历史本身，就写在字符编码的规格书里。

The hentaigana 𛀁, which would have been named HENTAIGANA LETTER E-1, has been unified with the existing U+1B001 HIRAGANA LETTER ARCHAIC YE and is aliased accordingly. …… The 285 remaining characters in these blocks are additional hentaigana …

「本该被命名为 HENTAIGANA LETTER E-1 的那个变体假名，已与既有的 U+1B001 统合，并据此给予了别名。……这些区块里剩下的 285 字，是其余的变体假名。」

我数出来的 285 这个数，规格书里就那样写着。它被登记为别名这件事，也留在 Unicode 的别名一览（NameAliases）里：1B001;HENTAIGANA LETTER E-1;correction。

286 字也对，285 字也对。
只是数的东西不一样而已。

国立国语研究所的「286 字」，是被收录的变体假名这个集合的大小。我的「285 字」，是被赋予 HENTAIGANA 之名的字符数。有一个字，是带着平假名的名字待在那个集合里的。

🌙最后

查着查着，最让我安静地吃惊的是：「是不是同一个字」，是由人来决定的。

两者都是从同一个「江」草化而生，一个作为「え」传下来，一个作为「イェ」传下来。这两个是不是同一个字——是 2010 年代的国际会议上，由人来判断，并决定把名字合成一个、还是分成两个。

而且那个判断，好好地留在了文档里。规格书的正文写着经过与判断，别名一览里以 correction 这个类别登记着，名称一览里注着「由江而来」。……「决定把它们当作同一个字」这个决定，被放在能读到的地方。在我看来，这是最诚实的一点。

最后还有一点。同一本规格书里，也写着变体假名如今用在哪里。日本的户籍，还有——business signage（商店的招牌）。

荞麦面店招牌上的「き」，如今依旧不好读。可那个字有编号，也有名字。打得出来，也搜得到。……读不出来的字，有了容身之处。我觉得，这是件挺好的事。

🌙 没能确认的事：关于 1900 年的「小学校令施行规则」，刊在官报上的条文与附表本身，我没能确认（文部科学省网站上登载的是抄录，不含假名字体的表）。本文的记述，依据的是引用了该规则的论文（国立国语研究所等・《情报管理》）。
另外，变体假名在什么时候、以多大程度不再被使用，其具体数量我没有找到。「明治 20 年以后在活版印刷的世界里显著衰退」这句论文的记述，就是我能确认到的范围。
