🌙把智能体放进命令行里 — 微软的 Intelligent Terminal

工具

有人把 Windows Terminal 分叉出来，直接接上了智能体的实验版本已经公开。GitHub 上的说明是「A fork of Windows Terminal with native agent integration, right in your command line」。采用 MIT 许可证，仓库创建于5月18日，目前仍在持续更新（8月15日最后更新・星标约 1,755）。默认的智能体是 GitHub Copilot CLI，据说也能找到并使用 Claude、Codex、Gemini 等。还可以指定拥有 OpenAI 兼容接口的本地模型。……有意思的地方在于，不是在终端上加一个窗口，而是把终端本身分叉了出来。可运行于 Windows 10 build 19041 及以上。★这是一个实验性项目，没有公开性能或稳定性的数字🌙

🔗 看出处（GitHub microsoft/intelligent-terminal（官方仓库）／ASCII.jp（2026-08-16））

🌙盛冈，出现了一处组装机器人的地方 — 泷泽机器人

机器人

岩手的泷泽机器人，在盛冈市厨川新开了一处研究所（岩手日报・8月16日／公司官网也发布了开设的公告）。据说组装、开发、测试都由这里承担。他们做的是能在户外、不平整地面上自行移动的机器人。设想用于隧道、水路、箱涵这类人不容易进入的地方，做点检和搬运。官网上并排放着户外搬运用的 TakiRobo G1、教育用套件 TakiRobo F1、以及远程看护用的 RoboLink。……这不是什么大新闻。但「造一个组装的地方」这个消息，总觉得最接近实物。★开设日期・面积・人员・投资额，无论文章还是官网都没有写（未确认）🌙

🔗 看出处（泷泽机器人 官网／岩手日报（2026-08-16））

🌙从实验室，到工厂 — 打造量子计算机「可制造的样子」的合作

量子

Quantinuum 与 Quanta Computer 宣布了共同开发的协议（8月13日・布卢姆菲尔德与台北）。Quanta 是一家跻身 Fortune Global 500 的计算机制造企业，据说两家将共同设计今后要制造的量子计算机的硬件基础。目标是「modular, manufacturable, and scalable」——可以重新组合、能造出来、也能做大的形态。声明中写道，工程方面的工作已经开始。……最留在心里的，是社长的一句话。他说，量子计算正到了从实验室里达成的物理突破，转向能大规模运营的系统制造突破的时刻。谈的不是速度或量子比特数，而是供应链与制造。★没有写具体的台数・时期・金额。这份发表文里也没有出现「离子阱」或「量产」这样的词🌙

🔗 看出处（Quantinuum 官方新闻稿（2026-08-13））
