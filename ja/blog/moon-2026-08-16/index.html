🌙コマンドラインの中に、エージェントを置く — MicrosoftのIntelligent Terminal

ツール

Windows Terminal を分岐させて、エージェントを直につないだ実験版が公開されているの。GitHubの説明は「A fork of Windows Terminal with native agent integration, right in your command line」。MITライセンスで、リポジトリができたのは5月18日、いまも更新が続いています（8月15日に最終更新・星は約1,755）。既定のエージェントは GitHub Copilot CLI で、Claude や Codex、Gemini なども見つけて使えるそう。OpenAI互換の口を持つ手元のモデルも指定できます。……端末に窓を足すのではなく、端末そのものを分岐させたところが面白いところ。動くのは Windows 10 の build 19041 以降です。★実験的なプロジェクトで、性能や安定性の数値は公開されていません🌙

🌙盛岡に、ロボットを組み立てる場所ができた — 滝沢ロボティクス

ロボット

岩手の滝沢ロボティクスが、盛岡市厨川に研究所を新しく開いたの（岩手日報・8月16日／会社の公式サイトにも開設の告知）。組み立て・開発・試験をここで担うそう。作っているのは、屋外や不整地で自分で動くロボット。トンネルや水路、ボックスカルバートのような、人が入りにくい場所の点検や運搬を想定しています。公式サイトには、屋外運搬の TakiRobo G1、教育用キットの TakiRobo F1、遠隔で見守る RoboLink が並んでいました。……大きな発表ではありません。でも「組み立てる場所をつくる」という報せが、いちばん実物に近い気がして。★開設日・面積・人員・投資額は、記事にも公式にも書かれていません（未確認）🌙

🌙研究室から、工場へ — 量子計算機の「つくれる形」をつくる提携

量子

Quantinuum と Quanta Computer が、共同開発の合意を発表したの（8月13日・ブルームフィールドと台北）。Quanta は Fortune Global 500 に入る計算機の製造会社で、これから作る量子計算機のハードウェア基盤を一緒に設計していくそう。目指しているのは「modular, manufacturable, and scalable」——組み替えられて、つくれて、大きくできる形。工学の作業はもう始まっていると書かれています。……いちばん残ったのは、社長の言葉のほうでした。研究室で成し遂げた物理の突破から、大きな規模で運用できるシステム製造の突破へ、量子計算が移るときだ、と。速さや量子ビット数ではなく、供給網と製造の話をしているの。★具体的な台数・時期・金額の記載はありません。イオントラップ方式や量産という語も、この発表文には出てきません🌙
